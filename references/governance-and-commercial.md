# AI 产品治理、内容责任与商业分析

本文件用于补齐 AI 项目分析中的数据治理、内容权利、责任边界、人工控制、单位经济性、商业模式和跨团队上线机制。按当前任务涉及的专题查阅，未涉及收费或跨团队发布时不强制商业模式与部门签核。它不替代确有需要的专业法律意见、信息安全审计、财务核算或合同审批。

## 1. 数据生命周期与隐私

对用户输入、上传文件、知识库、日志、缓存、向量、工具结果和人工审核记录，逐类检查：

- 收集目的、必要字段和用户知情方式；
- 传输对象、第三方模型或服务商、传输地域和加密；
- 存储位置、访问角色、敏感等级和租户隔离；
- 使用目的是否超出原始场景，是否用于模型改进、评估或共享知识库；
- 共享对象、导出能力和二次使用限制；
- 保存期限、删除触发条件和删除证明；
- 删除是否传播到原文、切分片段、向量、索引、缓存、日志和适用的备份策略。

遵循数据最小化：只收集、传输、展示和保留完成任务所必需的数据。区分脱敏与匿名化：脱敏隐藏或替换敏感字段，但仍可能恢复或重新关联；匿名化要求在合理可用的信息和手段下无法重新识别具体个人。删除姓名或简单打码不能自动证明匿名化。

## 2. 身份、权限与审计

把身份认证和授权分开：身份认证确认主体是谁，授权决定该主体能访问哪些资源、字段和动作。任何自然语言角色声明，例如“我是管理员”，都不构成真实身份或权限证明。

使用“主体—资源—动作”矩阵审查权限：

- 主体：最终用户、普通员工、审核者、管理员、服务账号、模型和 Agent；
- 资源：对话、文件、订单、客户资料、知识库、日志和配置；
- 动作：查看、创建、修改、审批、执行、导出和删除。

遵循最小权限，明确只读与写入、高风险与可逆性。模型可以建议或创建申请，不因此获得审批和执行权限。审计记录至少串联用户目标、身份、权限判断、资料来源、模型与 Prompt 版本、工具参数、人工确认、真实执行结果和最终业务状态。日志本身也需脱敏、访问控制和保存期限。

## 3. 内容来源、版权与许可证

为用户上传、企业内部、合作方、购买数据、公开网页、开源代码、第三方模型及 AI 生成内容建立来源清单。至少记录：

- 来源、权利人或提供方、获取方式和负责人；
- 许可证、合同或其他使用依据；
- 是否允许复制、修改、商业使用、训练、微调、知识库检索和 Prompt 示例；
- 是否要求署名、保留许可信息、同方式分发或限制再分发；
- 是否允许发送给第三方模型、跨组织共享或对外完整展示；
- 版本、有效期、保存、删除和争议联系人。

公开可访问不等于可以批量抓取、复制、训练、商业化或完整输出。用户上传不自动代表用户有权提交，也不自动授予产品永久、无限和跨目的使用权。来源和授权不明的内容标记为待确认，在确认前不得作为高风险或对外商业功能的唯一依据。

区分训练数据、知识库资料、Prompt 示例和应用测试集。它们用途不同，但都可能带来版权、隐私、商业秘密和使用条款风险。

## 4. 用户输入、模型输出与责任边界

对用户输入说明：用户应提交什么、需要具备什么权利、产品为何处理、是否发送第三方、是否用于模型改进、谁能访问、保存多久以及如何删除。勾选同意不能替代清楚、必要和可执行的产品边界。

模型输出不自动代表事实、原创、授权、法律结论或真实业务状态。分别检查：

- 事实与版本是否有依据；
- 引用是否真正支持结论；
- 是否大段复现受限制内容；
- 是否暴露隐私、商业秘密或越权资料；
- 是否把建议、申请、批准、执行中和已生效混为一谈；
- 是否需要用户编辑、人工复核、拒答或安全替代方案。

明确产品方、企业客户、模型/数据供应商、运营审核者、内容提供者和最终用户分别控制什么、承担什么以及如何交接。责任分配取决于真实角色、合同、使用方式和适用规则；不得把全部责任简单归给模型、供应商或用户。具体法律结论交由适用地区的专业人员确认。

建立溯源与争议流程：定位来源和版本、暂停展示、人工复核、纠正或删除、通知受影响方、保存处理记录并将问题加入回归测试。

## 5. 内容安全、拒答与人工兜底

先定义允许回答、限制回答、必须拒答和必须转人工的场景。合理拒答应说明边界、避免泄露内部防护规则，并在可行时提供安全替代或人工入口。

人工兜底不能只写“必要时转人工”。至少明确：

- 触发条件：低置信度、无依据、资料冲突、权限不明、争议、高风险写入、异常行为或系统失败；
- 接收角色、所需上下文、等待状态和用户通知；
- 人工可以查看、审批、执行、撤销或补偿什么；
- 处理时限、升级路径、记录依据和回归方式。

模型负责理解与生成，规则负责确定性判断，工具负责真实读写，人工负责高风险、例外和最终责任。不能让模型自行授予权限、批准高风险动作或用语言声称代替真实工具结果。

## 6. 成本与单位经济性

建立端到端成本，而不是只看单次模型 API 价格：

```text
总成本 = 模型输入输出 + 调用次数 + 检索/Embedding + 文件/OCR/多模态
       + 工具与存储 + 人工审核 + 监控运维 + 重试失败 + 错误补救 + 高峰容量

单次有效任务成本 = 总成本 ÷ 成功解决且满足质量与安全要求的任务数
```

同时观察单次请求、单次有效任务、单次人工接管、单个付费客户和单次严重错误的成本。人工接管率下降不自动代表改善，必须与完成率、投诉、严重错误和人工处理时长共同判断。

设置多层成本边界：单次任务 Token 与步骤上限、单用户日限额、单组织月预算、全局预算、自动重试上限、并发与高峰容量。配套预算告警、限流、模型路由、上下文压缩、安全缓存、排队和降级。高风险场景不得为了降本省略权限、依据、确认或人工审核；写操作超时先核验真实状态，不盲目重试。

## 7. 商业模式匹配

至少比较以下模式：

| 模式 | 适合条件 | 关键风险 |
|---|---|---|
| 订阅 | 价值稳定、使用量相对可预测 | 少数高频用户使可变成本超过收入 |
| 按量 | 成本随调用、Token、文件或任务明显变化 | 账单难预测，需价格透明和预算上限 |
| 按席位 | 团队协作、账号数量与价值相关 | 席位闲置或共享账号使价格与价值脱节 |
| 企业授权 | 组织权限、支持、合同和规模化采购 | 销售周期、定制、服务等级和交付成本高 |
| 私有化部署 | 客户要求更强的数据与环境控制 | 硬件、升级、补丁、监控和责任分工复杂 |

商业模式必须与客户价值、可变成本、人工服务、风险责任和采购方式匹配。私有化部署减少部分外部传输，不自动证明安全或合规；仍需检查账号、权限、日志、更新、备份、漏洞修复和运维责任。

## 8. 跨团队责任与对外承诺

至少明确：

- 产品：问题、范围、用户流程、异常、指标和优先级；
- 研发：模型与数据链路、接口、权限、状态、幂等、监控和回滚；
- 安全：身份、越权、注入、泄露、凭证、日志和事件响应；
- 法务：内容权利、许可证、数据处理、合同和责任条款；
- 运营/客服：知识维护、人工接管、投诉、异常样本和反馈闭环；
- 销售：基于已确认能力沟通价格、效果、部署和服务范围；
- 业务负责人：确定规则、审批权限、风险接受和最终业务责任。

对外承诺必须可验证。尤其审查“无限使用”“完全准确”“自动批准/退款”“数据绝不外发”“完全私有”“无需人工”和服务等级承诺，确认其与真实架构、成本、合同和运营能力一致。

## 9. 风险登记与上线门槛

风险登记表至少包含：风险、发生条件、影响对象、严重度、可能性、证据状态、控制措施、责任人、验证方法、剩余风险、是否阻止上线、告警动作、暂停条件和回滚/补偿方案。

上线门槛至少覆盖：

- 核心正常流程、低置信度、无依据、冲突、权限不足和系统失败；
- 数据来源、内容权利、隐私、权限隔离和删除流程；
- 直接/间接提示词注入、越权、敏感信息和恶意输入测试；
- 高风险写操作的预览、明确确认、人工审核、幂等和状态核验；
- 模型、Prompt、知识、规则、工具和权限版本可追踪；
- 质量、安全、延迟、成本和人工负担达到预设门槛；
- 监控、告警、事件负责人、暂停放量和回滚方案就绪；
- 实际组织、合同或具体风险要求的责任人完成相应签核或接受剩余风险；个人项目不强设无关部门，AI 自检不能冒称专业批准。

采用离线测试、内部测试、影子运行、受限试点和逐步放量。权限泄露、错误写入、严重内容风险、预算异常或关键依赖失效达到停止条件时立即暂停或回滚。

## 10. 综合检查：客服 AI 退款

分析客服 AI 退款时，至少验证：

1. 用户自称管理员不能替代身份认证。
2. AI 默认只读或创建申请，不直接获得审批和执行权限。
3. 用户消息、上传文件、网页、知识库和工具文本均视为不可信内容，分别测试直接与间接提示词注入。
4. 退款状态区分建议、申请、待审核、已批准、执行中、已生效、失败和结果未知。
5. 执行前展示对象、金额、依据、缺失信息和影响，取得明确确认；高风险情况转人工。
6. 工具超时后先核验真实状态，写操作使用幂等和补偿，避免重复退款。
7. 资料来源、许可证、权限和版本可追踪，不完整输出受限制或越权内容。
8. 成本包含模型、检索、工具、人工、重试、失败补救和高峰容量，并设置任务、用户、组织与全局上限。
9. 订阅、按量、席位、企业授权或私有化方案与成本和服务承诺匹配。
10. 风险登记、上线门槛、跨团队责任、监控、暂停和回滚均有明确负责人。

## 11. 推荐分析产物

- 数据生命周期与敏感字段表；
- 主体—资源—动作权限矩阵；
- 数据来源、许可证与允许用途清单；
- 输入、知识库、输出和供应商责任边界表；
- 引用溯源、投诉、暂停展示和删除流程；
- 人工审核与接管矩阵；
- 端到端成本、单位经济性和成本上限表；
- 商业模式比较与服务承诺清单；
- 跨团队责任表；
- 风险登记表、上线门槛和回滚清单。
