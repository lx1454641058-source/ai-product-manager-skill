# AI Product Manager Skill

一个面向 Codex 的 AI 产品经理 Skill，用于把模糊产品想法推进为可评审、可验证、可交付的 AI 产品方案。

## 能做什么

- 覆盖问题发现、用户研究、竞品分析、AI 可行性、产品方案、PRD、评估、指标、MVP、成本风险、试点上线和复盘。
- 持续标注 `✅ 已完成`、`🟨 待验证`、`🔵 需用户决策` 和 `⚪ 未开始`。
- 在需要时检索公开数据，给出低位、基准、高位区间，并说明来源、口径、计算方式和不确定性。
- 为 AI 输入输出、异常处理、人工接管、权限、安全、指标和测试集提供结构化模板。
- 不把假设写成事实，不把学习案例写成真实上线项目。

## 安装

将仓库克隆或下载到 Codex 的个人 Skills 目录：

```text
~/.codex/skills/ai-product-manager
```

重启或重新打开 Codex 任务后，使用：

```text
$ai-product-manager
```

示例：

> 使用 $ai-product-manager 分析我的 AI 产品想法，从全流程状态看板开始，标注已完成、待验证和需要我决策的部分，并为关键数据提供数值区间。

## 工作流程

Skill 内置 14 个阶段：

1. 项目框定
2. 问题、用户与场景
3. 证据与用户研究
4. 市场、竞品与替代方案
5. AI 适用性与可行性
6. 产品方案与用户流程
7. PRD
8. 评估与测试
9. 指标体系
10. MVP 与优先级
11. 成本、收益与商业判断
12. 安全、隐私与合规
13. 试点、上线与运营
14. 复盘与作品沉淀

## 数据与估算原则

所有重要数值应尽量说明：

- 指标定义、时间、地区和单位；
- 低位、基准和高位；
- 数据来自用户输入、公开资料、推算还是假设；
- 来源、计算逻辑、置信度和误差；
- 数据不足时明确表示不确定。

## 适用边界

本 Skill 提供产品分析框架，不代替法律、医疗、财务、安全或行业专业意见。公开数据和估算区间只用于产品规划，不代表实际业务结果。
