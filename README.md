# AI Product Manager Skill

一个面向 Codex 的 AI 产品经理 Skill，用于分析需求、选择方案、推进当前阶段，并以实际成果验收。默认聚焦当前任务，需要完整生命周期规划时再展开全部阶段。

## 工作深度

- **当前任务（默认）**：方案判断、需求审核、局部调整；给出结论、依据和必要的改动或建议，不强制新建计划。
- **阶段推进**：近期计划、多步骤执行和接续；复用已有主计划，只更新受影响的任务、依赖和验收。
- **完整生命周期**：明确要求从问题发现到移交退场，或项目已有此管理要求时，覆盖十阶段、34个来源步骤；不适用项说明原因。

“给个计划”“做个计划表”“继续”不会单独触发全生命周期。参考资料按需查阅，已读且未变的内容可以复用。

## 覆盖范围

- 问题、用户、场景、目标和替代方案
- 人工智能、机器学习、深度学习、大语言模型和模型能力边界
- 数据、特征、标签、训练、推理、过拟合、泛化、预训练、微调、对齐和幻觉
- Token、上下文窗口、截断、压缩、上下文污染、模型选择、成本和延迟
- 知识库、文档解析、OCR、切分、元数据、版本、权限、Embedding、向量数据库、混合检索、召回、重排、引用和 RAG
- Agent、规划、工作流、记忆、工具契约、权限、幂等性、超时、重试、循环控制、人工确认和审计
- 文本、图片、语音、视频等多模态输入及其质量风险
- 评估集、离线评估、在线指标、可观测性、缓存、流式输出、限流、降级、单位经济性和上线复盘

## 使用方式

将本目录安装到 Codex 的个人 Skills 目录：

```text
~/.codex/skills/ai-product-manager
```

然后使用：

```text
$ai-product-manager
```

示例：

```text
使用 $ai-product-manager 检查当前方案，给出最重要的改进及验证方法。

使用 $ai-product-manager 继续当前阶段，复用已有计划，完成已经授权的下一项成果。

使用 $ai-product-manager 为这个项目编写从问题发现到移交退场的完整生命周期计划。
```

用户只要求分析或计划时，不擅自实施；要求实施时，继续完成能力和授权范围内的制作、实现与验证。个人项目不强设企业岗位，内部任务可按约定测试或 AI 自检判定完成，不要求用户逐项签收。真实用户体验、独立移交或实际要求的专业验收仍需对应证据。

与个人总管等工作流配合时，共用项目目标、授权和主计划，不另建审批链。技能本身不会增加工具权限、开通服务或在聊天结束后自动运行。

## 适用边界

本 Skill 提供 AI 产品判断和推进方法，不代替确有需要的专业意见或真实签核。付款、发布、生产修改、破坏性操作等继续服从用户和所在环境的具体授权要求；已有有效授权在原范围内复用，不重复确认。

这是个人学习与分析项目，不代表真实公司项目或生产系统经验。

## 验证范围

已检查技能格式、配置、相对引用和34步覆盖一致性，并完成阶段推进与完整生命周期两个隔离场景演练。演练产物不能代表真实用户验证或长期效果；没有对成本、速度或质量提升作量化承诺。
