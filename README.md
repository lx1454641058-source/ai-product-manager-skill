# AI Product Manager Skill

一个面向 Codex 的 AI 产品经理 Skill，用于把模糊的 AI 产品想法推进为可评审、可验证、可交付的系统方案。

## 覆盖范围

- 问题、用户、场景、目标和替代方案
- 人工智能、机器学习、深度学习、大语言模型和模型能力边界
- 数据、特征、标签、训练、推理、过拟合、泛化、预训练、微调、对齐和幻觉
- Token、上下文窗口、截断、压缩、上下文污染、模型选择、成本和延迟
- 知识库、文档解析、OCR、切分、元数据、版本、权限、Embedding、向量数据库、混合检索、召回、重排、引用和 RAG
- Agent、规划、工作流、记忆、工具契约、权限、幂等性、超时、重试、循环控制、人工确认和审计
- 文本、图片、语音、视频等多模态输入及其质量风险
- 评估集、离线评估、在线指标、可观测性、缓存、流式输出、限流、降级、单位经济性和上线复盘

## 使用方式

将本目录安装到 Codex 的个人 Skills 目录：

```text
~/.codex/skills/ai-product-manager
```

然后使用：

```text
$ai-product-manager
```

示例：

```text
使用 $ai-product-manager 对我的企业知识库问答项目做一次完整分析，覆盖知识库、向量检索、模型上下文、工具调用、重试、评估、成本、安全和上线方案。
```

每次分析都会从项目目标和用户问题开始，逐项检查系统边界、知识与数据、模型与上下文、检索与引用、Agent 与工具、评估、成本、安全、上线和长期演化；对不确定信息标注依据，不把假设写成事实。

## 适用边界

本 Skill 提供 AI 产品分析和系统设计框架，不代替法律、医疗、财务、安全或行业专业意见。高风险场景必须保留证据、权限控制、人工确认和审计记录。

这是个人学习与分析项目，不代表真实公司项目或生产系统经验。
